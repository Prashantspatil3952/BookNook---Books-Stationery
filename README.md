# BookNook - Books & Stationery 📚

BookNook is a simple and responsive online bookstore and stationery website.

It allows users to browse books, search for titles and authors, explore book categories, view author pages, read reviews, add books to a cart, complete a checkout flow, and view their order history.

The project is built completely with HTML, CSS, and JavaScript and works locally without requiring an internet connection.

## Features

- 📚 Book catalog
- 🔎 Search books by title, author, or category
- 🗂️ Book categories
- ↕️ Sort books by price and rating
- 📖 Book details and specifications
- ⭐ Book ratings and reviews
- ✍️ Author pages
- ✏️ Books & stationery section
- 🛒 Shopping cart
- ➕ Increase or decrease quantity
- ❌ Remove products from cart
- 💳 Checkout page
- 📦 Delivery details
- 💰 Payment method selection
- ✅ Order confirmation
- 🧾 Order history
- 📱 Responsive design
- 💾 LocalStorage for cart and orders

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
